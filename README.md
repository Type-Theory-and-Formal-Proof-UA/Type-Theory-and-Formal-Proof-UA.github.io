# Type-Theory-and-Formal-Proof-UA.github.io

Landing page of the organisation's GitHub Pages site
(<https://type-theory-and-formal-proof-ua.github.io/>). The books themselves
live in their own repositories and are published under their repo names:

- `/ttfp/` — Type Theory and Formal Proof, Ukrainian translation
- `/sicp/` — SICP (Python edition), Ukrainian translation
- `/ATTaPL/` — Advanced Topics in Types and Programming Languages, Ukrainian translation

To add a book: enable Pages in its repository, then add an entry to the list
in `index.html`.
